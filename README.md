# LEGO Set Explorer | Power BI Dashboard

## Project Overview
Developed an interactive Power BI dashboard to explore 4,385 LEGO sets, focusing on product pricing, piece counts, and set characteristics. The dashboard allows users to filter and compare products through interactive visualizations.

## Dashboard Preview

![LEGO Dashboard](Lego%20dashboard.png)

## Tools & Skills
- **Power BI:** Dashboard development and data visualization
- **DAX:** Calculated measures and dynamic KPIs
- **Data Analysis:** Product comparisons and exploratory analysis
- **Interactive Reporting:** Slicers, filters, and data exploration

## Dashboard Features
- Key performance indicators displaying total LEGO sets, average price, and average piece count
- Interactive filters for theme groups, themes, age ranges, and pricing
- Set-level visualizations for comparing product characteristics
- Interactive table for exploring individual LEGO sets

## Project Highlights
- Analyzed 4,385 LEGO sets.
- Developed DAX measures to summarize product information.
- Created interactive visualizations to support product comparisons.
- Designed a dashboard that allows users to explore LEGO product data.
